## Resumen

La sesión se centra en las novedades de Microsoft Fabric para el verano de 2025 y en el arranque de la segunda temporada de ADN Fabric. Los ponentes repasan tanto cambios de producto como iniciativas de comunidad, incluyendo una nueva web con contenidos escritos de las sesiones, continuidad del canal de YouTube, repositorio en GitHub y una nueva dinámica con invitados expertos. También anuncian su participación en la conferencia europea de Fabric en Viena, reforzando el enfoque de divulgación práctica para la comunidad de datos.

Uno de los temas principales es el cambio en los modelos semánticos predeterminados. Hasta ahora, al crear ciertos elementos como una base de datos SQL en Fabric, se generaba automáticamente un modelo semántico junto con el punto de análisis. Microsoft cambia este enfoque para dar más control y gobierno a los equipos: a partir de septiembre de 2025 deja de crearse automáticamente el modelo semántico en nuevos recursos, y en una segunda fase los modelos creados previamente pasarán a ser responsabilidad del propietario del área de trabajo. Para los profesionales de datos, esto implica una mayor necesidad de diseñar, mantener y gobernar explícitamente sus modelos semánticos, en lugar de depender de automatismos iniciales.

Otro bloque relevante es la integración de Cosmos DB en Microsoft Fabric. Se explica como una base de datos NoSQL optimizada para escenarios de IA, ahora conectada al ecosistema de Fabric y OneLake. Esta integración permite combinar en consultas datos semiestructurados de Cosmos DB con datos relacionales de SQL, habilitando escenarios analíticos más ricos y flexibles. Además, se destaca que los datos pueden aprovecharse en procesos de ciencia de datos, machine learning e inteligencia artificial, gracias a su disponibilidad en formatos como Parquet dentro del entorno unificado de Fabric.

La sesión también subraya capacidades prácticas asociadas a Cosmos DB y al ecosistema Fabric: consultas cruzadas entre distintos orígenes, migración de datos mediante flujos y canalizaciones, operaciones de integración con APIs y GraphQL, y soporte de lenguajes de consulta NoSQL junto con opciones SQL ANSI y Transact-SQL a través de SQL Analytics endpoint y mirroring. Aunque varias de estas capacidades están en preview, el mensaje para los profesionales de datos es claro: Fabric sigue ampliándose como plataforma unificada donde conviven analítica, ingeniería de datos, modelado semántico y cargas operacionales, por lo que conviene seguir de cerca el roadmap, los permisos de tenant y la evolución de las funcionalidades en producción.
