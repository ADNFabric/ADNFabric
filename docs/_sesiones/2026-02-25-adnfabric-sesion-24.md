## Resumen

La sesión 24 de ADN Fabric se centró en la relación entre **Microsoft Fabric y Azure Databricks**, con la participación de Nicolás Nacazone como invitado principal. Antes del bloque técnico, se repasaron varios eventos relevantes de la comunidad, como sesiones del Microsoft Reactor, el bootcamp, el Power BI Fabric Summit y la European Fabric Community Conference, destacando el fuerte movimiento de la comunidad hispanohablante alrededor de Fabric. También se anunció la siguiente sesión, dedicada a bases de datos de grafos en Microsoft Fabric.

En el apartado de novedades, se presentaron varias mejoras importantes del ecosistema de Fabric. Se destacó la disponibilidad general de **Semantic Link**, una biblioteca de Python orientada a trabajar con modelos semánticos desde código, especialmente útil para escenarios analíticos avanzados. También se comentó la evolución de la **seguridad en OneLake**, con especial atención a la gestión más granular de roles mediante API, un aspecto clave para el gobierno y la protección de datos a nivel de archivos. Este punto es especialmente relevante porque anticipa una integración más profunda entre seguridad, Direct Lake y futuras capacidades de control de acceso.

Otro bloque importante fue el de productividad para ingeniería de datos y desarrollo. Se explicó la mejora de la extensión **Fabric Data Engineer para Visual Studio Code**, que ahora permite abrir y editar notebooks de Fabric directamente desde VS Code sin necesidad de descargarlos previamente. Además, se introdujo la nueva capacidad de gestionar **conexiones dentro de notebooks**, alineándolas con el modelo general de conexiones de Fabric y Power BI. Esto facilita reutilización, seguridad y una experiencia más consistente para quienes desarrollan soluciones de datos en notebooks.

Para los profesionales de datos, la sesión puso de relieve varios mensajes clave: Fabric sigue consolidándose como una plataforma unificada para analítica, ingeniería y gobierno del dato; OneLake se posiciona como pieza central en almacenamiento y seguridad; y las mejoras en notebooks, conexiones y herramientas de desarrollo apuntan a una experiencia más madura para equipos de ingeniería de datos. Finalmente, la intervención de Nicolás abrió el foco hacia cómo **Fabric y Azure Databricks pueden convivir y complementarse**, combinando capacidades de analítica, experiencia de usuario y procesamiento de datos avanzado en arquitecturas modernas.
